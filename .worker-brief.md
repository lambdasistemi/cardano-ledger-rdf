# Worker brief — typed governance-action walker (closes #5, #6, #7)

## Goal

Replace the remaining `emitProposalDatumFallback` opaque emissions with typed walkers for the three governance-action constructors still under raw-bytes:

- #5 `parameter_change_action` (id 0) — gov_action_id + protocol_param_update record + optional policy_hash
- #6 `update_committee` (id 4) — gov_action_id + remove set + add map + new quorum
- #7 `new_constitution` (id 5) + `hard_fork_initiation_action` (id 1) — small typed records, bundled

Same pattern β used for native_scripts in #48 and the cert walker in #52: one shared walker module, dispatch from the proposal-datum emit site. Single bisect-safe commit closing all three tickets.

Other GovAction constructors (`treasury_withdrawal_action`, `no_confidence`, `info_action`) are already typed — do NOT touch them.

## Proposed RDF shape

### #5 parameter_change_action

```turtle
_:govAction1 a cardano:ParameterChange ;
  cardano:hasPriorAction _:hash_govactionid_… ;        # optional
  cardano:hasGuardPolicy _:hash_scripthash_… ;          # optional
  cardano:hasProtocolParamUpdate _:ppup1 .

_:ppup1 a cardano:ProtocolParamUpdate ;
  cardano:hasMinFeeA 44 ;                               # only fields actually set
  cardano:hasMaxTxSize 16384 ;
  cardano:hasDRepVotingThresholds _:ppup1_drepThresholds ;
  ...
```

Only set fields emit triples (sparse map semantics). Per-field predicate names align with CDDL labels, camelCased. Nested records (cost_models, ex_unit_prices, drep_voting_thresholds, pool_voting_thresholds) get their own typed sub-blocks. If a nested record gets large, package it like `pool_params` was packaged in the cert walker — sub-bnode + typed predicates.

### #6 update_committee

```turtle
_:govAction1 a cardano:UpdateCommittee ;
  cardano:hasPriorAction _:hash_govactionid_… ;       # optional
  cardano:hasNewQuorum "2/3"^^xsd:string ;            # unit_interval as "a/b"
  cardano:removesMember _:cred_committeecoldkey_… ;    # repeated
  cardano:addsMember _:committeeAdd1 .                 # repeated

_:committeeAdd1 a cardano:CommitteeAddition ;
  cardano:hasIdentifier _:cred_committeecoldkey_… ;
  cardano:termLimit 1234 .                              # epoch_no
```

### #7 new_constitution

```turtle
_:govAction1 a cardano:NewConstitution ;
  cardano:hasPriorAction _:hash_govactionid_… ;       # optional
  cardano:hasConstitution _:constitution1 .

_:constitution1 a cardano:Constitution ;
  cardano:hasAnchor _:constitutionAnchor1 ;
  cardano:hasGuardrailScript _:hash_scripthash_… .     # optional
```

Anchor reuses the existing `cardano:Anchor` shape (already declared from cert walker / proposal cluster). Grep for `cardano:Anchor` and reuse — do NOT redeclare.

### #7 hard_fork_initiation_action

```turtle
_:govAction1 a cardano:HardForkInitiation ;
  cardano:hasPriorAction _:hash_govactionid_… ;       # optional
  cardano:hasProtocolVersion _:protocolVersion1 .

_:protocolVersion1 a cardano:ProtocolVersion ;
  cardano:hasMajorVersion 11 ;
  cardano:hasMinorVersion 0 .
```
